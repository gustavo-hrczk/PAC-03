# Registro de decisões

Uma decisão por arquivo, nomeado `NNNN-titulo-em-slug.md`.

**Formato obrigatório:** contexto → decisão → alternativas descartadas → consequência.
Uma decisão só entra aqui se tiver **alternativa descartada**. Sem isso, é tarefa, não decisão.

**Status possíveis:** `Vigente`, `Substituída por NNNN`, `Revogada`.
Nada é apagado — decisão revista muda de status e aponta para a que a substituiu.

As decisões D01 a D12 estão consolidadas em `docs/00-historico/historico.md`, seção 6.
Decisões novas passam a ser registradas aqui, a partir de 0013.
